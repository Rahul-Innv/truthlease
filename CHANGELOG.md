# Changelog

All notable changes to TruthLease are documented here. The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project aims to follow [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- Bring-your-own-integrations setup journey for local OpenAI, Bright Data, TrueForge, and TruthLease services.
- Public, loopback-gated Run Now control for starting a genuine local investigation.
- Trace-bound evidence, native approval, atomic containment, and persisted-state verification contracts.

### Changed

- The browser can initiate an investigation but retains zero approval or retailer-mutation authority.
- Evidence receipt identity now distinguishes separate retrieval occurrences while preserving exact-retry idempotency.

### Fixed

- WSL MCP relay host discovery and strict fixed-upstream routing.
- UTF-8/mojibake defects in the evidence-ledger UI.
